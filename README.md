# CartoonStudio

Мобильный редактор покадровой 2D- и 3D-анимации на Godot 4.2.1.

## Что уже есть в проекте

### 3D
- Демонстрационная кукла из отдельных частей.
- Импорт ригнутой модели `.glb`.
- Выбор костей на экране и инструменты поворота, перемещения и масштаба.
- Переключение FK/IK: FK для ручного позирования, IK для перемещения конечной кости с CCD-решателем.
- Экспорт кадров 3D-анимации в MP4/H.264 через Android MediaCodec с сохранением в Movies/CartoonStudio (без аудиомикширования в этой версии).
- Ключевые кадры, дублирование, удаление и автоматические Tween-кадры.
- Интерполяция вращения костей через Quaternion slerp.
- Управление камерой жестами, сохранение и загрузка проекта.

### 2D
- Отдельный 2D-режим из кнопки `2D` в панели 3D.
- Импорт изображений PNG/JPG/WebP как независимых слоёв.
- Прямоугольники, круги и рисование пальцем/мышью.
- Простые суставы и визуальные связи-кости между ними.
- Перемещение слоёв, поворот и масштаб.
- Ключевые кадры, дублирование, удаление, Tween и воспроизведение с регулируемым FPS.
- Сохранение и загрузка 2D-проекта в локальное хранилище приложения.

### Android
- Android Storage Access Framework для выбора GLB и изображений.
- Не запрашивается широкое разрешение на чтение всего хранилища.
- GitHub Actions собирает AAR-плагин, подготавливает Gradle-шаблон Godot и экспортирует тестовый APK.

## Сборка APK через GitHub Actions

1. Загрузить файл `CartoonStudio-ready.zip` в корень репозитория (можно через GitHub в браузере с телефона).
2. Открыть вкладку **Actions** и запустить workflow **Build CartoonStudio APK**.
3. Workflow автоматически распакует ZIP, сохранит исходники в репозитории и продолжит сборку.
4. После зелёного завершения скачать `CartoonStudio-APK` в разделе Artifacts.

Для Godot 4.2.1 Android Gradle template должен иметь `android/.build_version` со значением `4.2.1.stable` и `android/build/.gdignore`. Workflow создаёт оба файла автоматически.

## Текущие ограничения

- 2D-кости сейчас являются визуальными суставами и связями; автоматическая деформация изображения по скелету (mesh skinning) ещё не реализована.
- 3D-позирование требует GLB с уже созданным Skeleton3D и skin weights. Автоматическое создание рига из обычной модели не входит в эту версию.
- На Android 3D-импорт пока ориентирован на самодостаточные `.glb`. Для `.gltf` с внешними `.bin` и текстурами нужен отдельный пакетный импорт.
- MP4 экспортирует видеоряд по сохранённым кадрам/ Tween-кадрам через Android MediaCodec. Микширование аудиодорожки в MP4, выбор разрешения и фоновой экспорт требуют следующего этапа.

## Версия

Godot 4.2.1 stable. Проект ориентирован на Android и альбомную ориентацию экрана.

### Новые инструменты 3D
- Независимые камеры анимации и экспорта; камера экспорта не записывается в ключевые кадры.
- Подъём/опускание точки наведения камеры, орбита и pinch-зум.
- Экранные и осевые X/Y/Z инструменты для движения, вращения и масштаба костей.
- Runtime-отображение скелета с подсветкой выбранной кости.
- Настройка позиции, вращения и масштаба корня 3D-модели.

## Звуковая дорожка и OBJ

- Добавлена независимая от кадров анимации звуковая дорожка: WAV, OGG и MP3.
- Можно импортировать несколько аудиоклипов, задавать время начала, менять общую громкость, перемещаться по аудиовремени, запускать и останавливать предпрослушивание.
- На Android звук выбирается через системный SAF-пикер и копируется в приватную папку приложения.
- Добавлен runtime-импорт Wavefront `.obj`: геометрия, UV-координаты, нормали, треугольные и выпуклые многоугольные грани.
- OBJ загружается как статическая сетка. Скелет, MTL-материалы и внешние текстуры OBJ пока не импортируются; для анимируемых персонажей используйте GLB с Skeleton3D.

### IK (обратная кинематика)
В инструменте анимации цикл режимов теперь включает `IK: цель`. Выберите конечную кость (например, кисть/стопу) и перетащите её в окне просмотра: CCD-решатель вращает цепочку родительских костей к целевой точке. Нужна ригнутая GLB/GLTF-модель с `Skeleton3D`. Ограничители суставов и pole target пока не входят в первую версию.

### FK / IK и MP4
- Кнопка `Режим: FK/IK` переключает способ позирования. FK: ручное вращение/перемещение/масштабирование выбранных костей. IK: перетаскивание конечной кости, CCD рассчитывает повороты цепочки родителей.
- `Экспорт MP4` захватывает каждый элемент таймлайна (включая созданные Tween-кадры), кодирует H.264 и сохраняет видео в `Movies/CartoonStudio` через Android MediaStore. В текущей версии экспортируется видео без аудиодорожки; звук остаётся доступен для предпрослушивания в редакторе.
- MP4-экспорт требует APK, собранный с обновлённым Android-плагином `GodotAndroidFilePicker`. На Android необходимо проверить поддерживаемый кодек и фактический вывод файла.
